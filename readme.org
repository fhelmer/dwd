* DWD ICON-D2 GRIB downloader

Downloads the most recent complete ICON-D2 forecast run from DWD open
data, merges the single-level fields into one GRIB file and cuts out
southern Sweden.

Source: https://opendata.dwd.de/weather/nwp/icon-d2/grib/
Example: https://opendata.dwd.de/weather/nwp/icon-d2/grib/12/

** Requirements

- Python 3 with =click=, =requests= and =beautifulsoup4=
- =bunzip2=
- =cdo= (Climate Data Operators)

** Usage

#+begin_src sh
# Find the most recent run cycle where all fields are available
python3 dwd_grib_downloader.py findlatest

# Download all fields for a given run cycle hour (0, 3, ..., 21)
python3 dwd_grib_downloader.py download --run_cycle_hour 12

# Find latest run, download, uncompress, merge, crop and upload to FTP
python3 dwd_grib_downloader.py makefinalgrib

# Only build and download if there is a newer run cycle than existing local GRIB files
python3 dwd_grib_downloader.py makefinalgrib --update

# Upload existing GRIB file to FTP server directly
python3 dwd_grib_downloader.py upload

# Download GRIB file from FTP server directly
python3 dwd_grib_downloader.py downloadftp

# Download from FTP only if there is a newer run cycle than existing local GRIB files
python3 dwd_grib_downloader.py downloadftp --update
#+end_src

=makefinalgrib= downloads into =./downloaded_files=, then:

1. =bunzip2 *.bz2=
2. =cdo merge *.grib2 combined.grib2=
3. =cdo select,minute=0 combined.grib2 final.grib2=
4. =cdo sellonlatbox,10,14,54,57 final.grib2 ../YYYYMMDDHH.grib2=
   (lon 10-14, lat 54-57, southern Sweden)
5. Deletes the intermediate =*.grib2= files
6. Uploads =./YYYYMMDDHH.grib2= to FTP server =helmer.se/grib= (skip with =--skip-upload=)

The result is =./YYYYMMDDHH.grib2= (e.g. =./2026110112.grib2=).

** FTP Configuration

FTP upload and download default to =helmer.se/grib= port 21. Credentials can be supplied via environment variables, CLI options, or =~/.netrc=.

- Environment variables:
  - =FTP_USER= (or =FTP_USERNAME=)
  - =FTP_PASSWORD= (or =FTP_PASS=)
  - =FTP_HOST= (default: =helmer.se=)
  - =FTP_DIR= (default: =grib=)
  - =FTP_PORT= (default: =21=)

- CLI options:
  - =--ftp-host=
  - =--ftp-user=
  - =--ftp-password=
  - =--ftp-dir=
  - =--ftp-port=
  - =--skip-upload= (on =makefinalgrib=)
  - =--update= (on =makefinalgrib= and =downloadftp=, only download if a newer run cycle exists)
  - =--file= (on =upload= and =downloadftp=)
  - =--remote-file= (on =downloadftp=)

** Algorithm

The following run cycles exist: 0,3,6,9,12,15,18,21
24/3=8

Time zone is UTC and then it takes about 01h40min until the files are available

So for 1800 forecast, it will be available around 2140
(2h time difference with DST + 1:40)

To find the latest complete run, the current hour is rounded down to the
nearest run cycle. A run cycle is complete when every file in each
field's directory has the run cycle timestamp (=YYYYMMDDHH=) in its
name. If not, step back 3 hours (from 00 to 21 on the previous day) and
check again.
